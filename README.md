# 勤務実績補助拡張

## 概要

Jinjer の勤怠ページ `https://kintai.jinjer.biz/staffs/time_cards` を見やすくして、入力作業をしやすくする Chrome 拡張です。

この版は、もともと入っていた既存機能に加えて、月次勤怠レスポンスを使った一覧表示の補助機能をまとめた完成版です。

## 対応ページ

- `https://kintai.jinjer.biz/staffs/time_cards`

## 動作環境

- Chrome 拡張（Manifest V3）
- Jinjer 勤怠ページ

## 主な機能

### 1. 月次勤怠レスポンスの取得

ページ内で取得される以下の API レスポンスを監視して、日ごとの勤怠状態を判断します。

- `/v1/dashboard/time_cards/time_cards_schedule_month`

このレスポンスを使って、未打刻判定、承認待ち判定、オーバーレイ表示、自動スクロールを行います。

### 2. 一覧ステータスの表示補助

一覧の各行について、レスポンス内容をもとに表示を補助します。

変更するのは次の 2 種類だけです。

- **承認待ち**
  - 実績はあるが、一覧の集計時間がまだ反映されていない行
  - 文字色は「所休」と同系色
  - 実績列には **出勤〜退勤の時間だけ** を表示します
  - 例: `08:30〜17:15`
- **未打刻**
  - 予定あり、実績なし、かつ当日以前の行
  - 文字色を赤に変更
  - 行全体を黄色で強調

変更しないもの:

- **承認済** の行はデフォルト表示のまま
- **勤務予定** の行はデフォルト表示のまま
- **休日** の行はデフォルト表示のまま

### 3. 未打刻オーバーレイ表示

未打刻が 2 件以上ある場合、レスポンス取得時にオーバーレイを表示します。

表示内容:

- `過去の勤怠に入力忘れがあります。入力してください。`
- `対象: M/D(曜)`

対象日は、**もっとも古い未打刻日** です。

OK ボタンを押すとオーバーレイは閉じます。

### 4. 自動スクロール

一覧表示時に、もっとも古い未打刻を見つけた場合は、
**もっとも古い未打刻日の 3 日後が一覧の下端に来る** ようにスクロールします。

見え方としては、
**もっとも古い未打刻が下から 4 番目あたりに来る** 想定です。

未打刻がない場合は、従来どおり **勤務予定の近く** に寄せるスクロールへ戻ります。

### 5. シフトテンプレート保存

勤怠入力フォームの現在状態を、ユーザーごとのテンプレートとして保存できます。

保存対象:

- 欠勤・出勤・退勤のラジオ状態
- 出勤・退勤の時刻入力
- 休憩入力
- 各入力エリアの HTML 状態

保存したテンプレートはプルダウンへ追加され、選ぶと画面へ反映されます。

### 6. シフトテンプレート削除

保存済みテンプレートを一覧表示して、複数選択で削除できます。

削除時には:

- プルダウンの項目も削除
- 現在選択中のテンプレートが消えた場合は選択状態も解除
- 保存していた選択記録も整理

を行います。

### 7. シフトテンプレートの選択状態を保持

前回選んだテンプレートをユーザー単位で保存し、再表示時に復元します。

保存済みテンプレートがなくなった場合は、無効な記録を自動で消します。

### 8. 一時保存と復元

勤怠編集画面でキャンセル系ボタンを押したときに、その日の入力内容を一時保存します。

保存対象:

- 出退勤入力
- 休憩入力
- 理由欄
- シフトプルダウンの状態
- 時間入力エリアの HTML

同じ日を開き直したときに、自動で復元します。

### 9. 理由入力支援 UI

理由欄の下に、ユーザーごとの設定可能な補助 UI を表示します。

できること:

- 勤務種別ボタンの選択
- 理由ボタンの複数選択
- タイトル文の編集
- 設定モードでボタンの追加・削除・並び替え・名称変更
- 設定内容の保存
- 設定内容のダウンロード

`default_config.json` を初期値として読み込み、ユーザーごとの設定で上書きして使います。

### 10. ラジオボタン表示の補正

ページ側のラジオボタン UI が重なることがあるため、見た目を補正しています。

補正内容:

- ラベルとの余白調整
- 高さ不足の補正
- 折り返し対応
- 元デザインに近い丸表示とチェック表示の維持

既存 HTML や本来の入力機能は変えず、CSS と軽い DOM 補正だけで調整しています。

## 実装方針

- 画面上の文字だけに頼らず、月次レスポンスを正として判定する
- 既存表示をできるだけ壊さず、必要な行だけ上書きする
- ユーザーごとのテンプレートや設定は `chrome.storage.local` に保存する

## まだ入れていないもの

この完成版には、次の機能は入れていません。

- 未打刻行の編集ボタン自動クリック
- `未打刻日があります。入力してください。` の自動ポップアップ起点で編集画面を開く処理

## 同梱ファイル

- `content.js`
  - メインの表示補助、テンプレート機能、理由 UI、スクロール制御
- `page_hook.js`
  - ページ本体側で fetch / XHR を監視して月次レスポンスを拾う
- `manifest.json`
  - Chrome 拡張の設定
- `README.md`
  - この説明書
